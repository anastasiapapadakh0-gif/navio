# NAVIO - Smart Bus Management System

## Overview

NAVIO is a smart bus management system developed as a university team project using React and Vite.

The application simulates the operation of an intelligent public transport bus by providing different interfaces for drivers, employees and passengers. Each user role has access to different tools and functions that support the daily operation of the vehicle.

## Features

### Driver
- Driving assistance with real-time safety alerts.
- Climate control based on weather conditions.
- Smart recommendations for passenger comfort.

### Employee
- Smart roof management based on weather conditions.
- Cleaning robot monitoring.
- Battery, cleaning progress and found items simulation.

## Technologies

- **React** – Used to build the user interface through reusable components.
- **React Router** – Used for navigation between application pages.
- **JavaScript (ES6)** – Used to implement the application logic.
- **CSS** – Used for styling and responsive design.
- **Vite** – Development and build tool used to create, run and bundle the React application.

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install the required packages:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
